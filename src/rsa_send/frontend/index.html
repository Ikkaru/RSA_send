RSA Send

Pengiriman citra dengan RSA-KEM, CRT, HKDF, dan AES-GCM

Kirim citra

Sisi client. Pilih citra, tentukan parameter, lalu kirim ke server.

Format gambar umum seperti PNG atau JPG.

Pengaturan lanjutan

Boleh dikosongkan. Server dan client harus memakai salt yang sama.

Boleh dikosongkan. Ikut diautentikasi oleh AES-GCM tetapi tidak dienkripsi.

Terima citra

Sisi server. Menampilkan data yang diterima dan hasil dekripsinya.

StatusMenunggu kiriman

Alur protokol

Klik langkah untuk melihat penjelasannya.

1 Buat kunci

Server membuat pasangan kunci RSA beserta parameter CRT dp, dq, dan q_inv.

rsa_generate_key_crt

2 Enkapsulasi

Client memilih angka acak z, lalu menghitung C = ze mod n.

rsa_kem_encapsulate

3 Turunkan kunci AES

HKDF mengubah z menjadi kunci simetris dengan panjang 16 atau 32 byte.

hkdf_extract, hkdf_expand

4 Enkripsi citra

AES-GCM mengenkripsi citra dan menghasilkan ciphertext beserta tag autentikasi.

aead_encrypt_decrypt

5 Dekapsulasi

Server memulihkan z dengan CRT, lalu menurunkan kunci AES yang sama.

rsa_kem_decapsulate_crt

6 Dekripsi citra

Tag diperiksa. Jika cocok, ciphertext dikembalikan menjadi citra asli.

aead_encrypt_decrypt
